## Как обновить существующий проект

1. Откройте текущий проект Akzhan Rehab в Cursor и найдите существующий index.html.
2. Скопируйте СОДЕРЖИМО папки akzhan-rehab-main из архива в эту же папку проекта. Подтвердите замену одноимённых файлов; папки объедините. Не создавайте внутри проекта дополнительный уровень akzhan-rehab-main.
3. Сохраните остальные файлы проекта и его существующие настройки подключения к GitHub и Vercel. Архив содержит статический сайт: новая установка npm и смена настроек сборки не нужны.
4. Проверьте изменения и отправьте их в ту ветку GitHub, из которой Vercel публикует основной сайт. Если автоматическая публикация включена, дождитесь успешного деплоя.
5. Откройте https://www.akzhanrehab.help/ и обновите страницу. Если домен уже связан с этим проектом Vercel, DNS менять не нужно.

## Что входит

- index.html, style.css и script.js — текущий дизайн и логика сайта.
- assets/ — локальные шрифты, лицензия, иконка и оптимизированные изображения.
- akzhan/images/ — оригиналы результатов и отзывов, необходимые для полноэкранного просмотра.
- Изображения карточек, файлы подтверждения Google и Яндекса, robots.txt и sitemap.xml.
- update-manifest.py — необязательный инструмент для добавления фотографий в галереи.

Анимация включена по умолчанию, в том числе при системном уменьшении движения. В меню и подвале остаётся выбор режима; явное отключение посетителем сохраняется. Ссылки canonical и социальных карточек настроены на основной домен, индексация разрешена.

Сайт работает на обычных HTML, CSS и JavaScript без сборки. Для локального просмотра можно открыть index.html; окончательно проверяйте поведение на опубликованной HTTP-версии. Обновление файлов само по себе не меняет настройки домена и не публикует сайт.
